## Reporting a Vulnerability

If you discover a potential security vulnerability, please report it privately rather than opening a public issue.

<!-- Replace this section with your preferred private reporting method. -->

Please report vulnerabilities through the repository's private security reporting mechanism.

When reporting a vulnerability, please include:

- A description of the vulnerability.
- The affected component or functionality.
- The affected version or version range.
- Steps to reproduce the issue.
- The potential impact.
- Any suggested mitigation, if known.

Please do not include passwords, authentication credentials, private information, or other sensitive data in the report unless specifically requested through a secure reporting channel.

## Response

We will review security reports and, where appropriate, investigate and address confirmed vulnerabilities.

Security reports may result in:

1. Confirmation and remediation of the vulnerability.
2. A request for additional information.
3. A determination that the reported behavior does not constitute a security vulnerability.

## Disclosure

Please allow reasonable time for a vulnerability to be investigated and addressed before publicly disclosing it.

Once a vulnerability has been resolved, relevant information may be included in release notes, security advisories, or other project documentation.

## Security Updates

Security fixes will be distributed through the project's normal release mechanisms where applicable.

Users are encouraged to keep their installation and dependencies up to date.
